# 사주 만세력

절기 기준 만세력으로 사주, 평생운, 궁합, 이름짓기를 한 번에 보는 웹 프로그램입니다.
서버 없이 브라우저만으로 동작합니다.

## 파일 구조

```
index.html        화면 구성과 디자인(CSS)
lunar.js          절기·간지 계산 라이브러리 (lunar-javascript 1.7.8, MIT 라이선스 — LICENSE-lunar-javascript.txt)
js/
  core.js         계산 엔진: 기본 데이터, 시각 보정, 사주 계산, 합·충, 신살
  hanja-db.js     대법원 인명용 한자 9,494자 데이터 (소리·뜻·원획·부수 기준 자원오행)
  reading.js      풀이 문장, 오늘·월별 운세, 평생 사주
  saju-view.js    사주 탭 화면, 저장 목록
  match.js        궁합 계산, 상세 풀이, 관계별 모드
  naming.js       이름 추천
  tools.js        내 이름 풀이, 운세 달력, 택일, 신년운세, 복사
  analysis.js     용신, 명식 상세, 합·충 그림, 인생 그래프, 커플 달력
  detail.js       상세 창(대운·세운·날짜), 이름 비교
  admin.js        관리자 모드 (PIN 잠금)
  extra-tabs.js   운세·택일 탭 안내줄, 띠별 운세, 만세력 탭(날짜 변환·월간 만세력·24절기)
  tojeong.js      토정비결 (전통 괘 산출 + 새로 쓴 풀이)
  dream.js        꿈해몽 사전 (약 100개, 새로 쓴 풀이)
  tarot.js        타로 메이저 아르카나 22장 (자체 카드 디자인)
  main.js         메뉴 전환과 시작
  dragon-holo.webp/png 상단 오른쪽 홀로그램 용머리 (떠오르기·스캔빛·깜빡임·여의주 빛)
  topbar.js       상단 날짜·시간·방문자 수·날씨 (Open-Meteo 날씨, GeoJS 지역 추정, CountAPI(mileshilliard) 방문자 카운터)
  tests.js        자동 테스트
```

`index.html`이 위 순서대로 파일을 불러옵니다. 순서를 바꾸면 동작하지 않을 수 있습니다.

## 내 컴퓨터에서 실행하기

폴더째 내려받은 뒤 `index.html`을 브라우저로 열면 됩니다.

## 자동 테스트

주소 끝에 `#test`를 붙여 열면(예: `index.html#test`) 테스트가 실행되고 결과 창이 뜹니다.
절기 경계(입춘·경칩 직전·직후), 서머타임, UTC+8:30 시기, 자시, 윤달, 십신·12운성 계산을 확인합니다.
코드를 고친 뒤에는 꼭 다시 돌려 보세요.

## 관리자 모드

- 페이지 맨 아래 **관리자** 버튼 → 처음에는 PIN을 정하고, 다음부터는 PIN을 입력합니다.
- 관리자일 때만 저장 버튼, 저장 목록, 궁합 탭의 '불러오기' 목록이 보입니다.
- 페이지를 새로 열면 다시 잠깁니다. 5번 틀리면 1분 동안 입력할 수 없습니다.
- 저장 정보와 PIN(해시)은 **이 기기의 브라우저에만** 저장되고 어디로도 전송되지 않습니다.
  다른 사람이 같은 사이트에 접속해도 내 목록은 보이지 않습니다.
- 저장 데이터 자체는 암호화하지 않았으므로, 기기를 다른 사람과 같이 쓴다면
  브라우저 개발자 도구로 볼 수 있다는 점에 주의하세요.

## GitHub Pages로 배포하기 (무료)

1. GitHub에 로그인 → 오른쪽 위 `+` → **New repository** → 이름 예: `saju` → **Public** → Create.
2. 저장소 화면에서 **Add file → Upload files** → 이 폴더의 `index.html`, `lunar.js`, `README.md`, `LICENSE-lunar-javascript.txt`와
   `js` 폴더를 통째로 끌어다 놓고 **Commit changes**.
3. 저장소의 **Settings → Pages** → Source를 **Deploy from a branch**, Branch를 `main` / `/ (root)`로 → **Save**.
4. 1~2분 뒤 `https://내아이디.github.io/saju/` 주소로 접속됩니다.

수정할 때는 바뀐 파일만 다시 업로드하면 몇 분 안에 사이트에 반영됩니다.

## 알려진 한계

- 용신은 억부와 조후를 단순화한 판단입니다.
- 이름 풀이는 대법원 인명용 한자 9,494자 전체를 쓰지만, 자원오행은 부수로 판단할 수 있는 글자(약 절반)만 자동으로 정해집니다.
- 원획은 대법원 데이터(부수 원래 획수 + 나머지 획수) 기준이라 일부 글자는 작명 유파와 1획 다를 수 있습니다.
- 새 이름 추천은 획수·오행을 직접 검증한 약 230자만 씁니다.
- 신살·궁합·작명 점수 기준은 유파마다 조금씩 다릅니다.
- 결과는 전통 명리 해석으로, 재미와 참고용입니다.
